# Copyright, source, and privacy boundary

The course videos, transcripts, slide PDFs, screenshots, private links, and access identifiers are source material supplied locally for Rahul's personal study. They do not belong in this public repository or bootstrap archive.

Tracked outputs must be transformative and original:

- explanations in new wording;
- reconstructed diagrams rather than copied slide images;
- faithful requirement checklists rather than long verbatim assignments;
- original examples, code, fixtures, calculations, and experiments;
- short source excerpts only when necessary for accuracy;
- timestamps and source uncertainty records without raw transcript blocks.

Never commit:

- `inputs/private/`;
- video/audio files;
- transcripts or subtitle files;
- course PDFs or screenshots;
- Drive URLs/IDs;
- credentials, tokens, personal data, or employer-confidential material.

External extensions use primary sources where possible and cite only material actually read. Do not imply that Arpit Bhayani endorsed Codex-added examples, tools, or solutions.
